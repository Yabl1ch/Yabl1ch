# Yabl1ch — Персональный сайт-визитка

Официальный персональный сайт-портфолио **Yabl1ch (Максим)**.

- **Сайт онлайн**: [https://yabl1ch.github.io/Yabl1ch/](https://yabl1ch.github.io/Yabl1ch/)

---

## О проекте

Современный интерактивный веб-сайт с кинематографичной анимацией заставки яблоневой рощи, темной изумрудной темой, подробной информацией (Bio) и интерактивной галереей проектов (My Work).

### Ключевые особенности
- **Заставка «Листья яблоневой рощи»**: 54 3D-листа яблони, летящие по ветровым дугам и собирающиеся в светящуюся эмблему за 1.6 секунды.
- **Интерактивный заголовок**: 3D-аватар с неоновым кольцом и посимвольная подсветка ника фирменным зеленым цветом.
- **Вкладки «Bio» и «My Work»**: плавное переключение с эффектом размытия и анимацией перехода.
- **Стилизованные соцсети**: карточки Telegram, Discord и GitHub с белым контрастным контуром и быстрым копированием контактов.
- **Галерея работ**: минималистичные превью карточек с модальным окном детального просмотра, полноэкранным слайдером скриншотов и описанием.
- **Мобильная адаптация**: полная поддержка экранов любых размеров с сохранением всех анимаций и жестов.
- **Векторная иконографика**: 100% чистый SVG (без эмодзи).

---

## Стек технологий

- **Фреймворк**: React 19 + TypeScript
- **Сборщик**: Vite 6
- **Стилизация**: Tailwind CSS
- **Анимации**: Framer Motion
- **Иконки**: Lucide React + Inline SVG
- **Хостинг**: GitHub Pages (автоматический CI/CD деплой через GitHub Actions)

## Локальный запуск

```powershell
# Установка зависимостей
npm install

# Запуск в режиме разработки
npm run dev

# Сборка продакшен-бандла
npm run build

# Предпросмотр сборки
```
