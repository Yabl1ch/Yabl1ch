---

## О проекте

Современный интерактивный веб-сайт с кинематографичной анимацией проявления фоновой сетки и звуковым приветствием, темной изумрудной темой, подробной информацией (Bio) и интерактивной галереей проектов (My Work).

### Ключевые особенности
- **Интро с проявлением сетки (0.7с)**: в первые 0.5 секунды из центра плавно проявляются квадраты фоновой сетки с изумрудным свечением, после чего звучит гармоничный аккорд (Web Audio API) и за 0.2 секунды появляется весь контент сайта.
- **Интерактивный заголовок**: 3D-аватар с неоновым кольцом и посимвольная подсветка ника фирменным зеленым цветом.
- **Вкладки «Bio», «My Work» и «My certificates»**: плавное переключение с эффектом размытия и анимацией перехода.
- **Галерея сертификатов (My certificates)**: карточки подтвержденных сертификатов по ИИ (Google Cloud, IBM SkillsBuild, Kaggle) с просмотром обложки, прямой ссылкой на проверку подлинности, копированием URL и доступом к оригинальным PDF-документам.
- **Стилизованные соцсети**: карточки Telegram, Discord и GitHub с белым контрастным контуром и быстрым копированием контактов.
- **Галерея работ**: минималистичные превью карточек с модальным окном детального просмотра, полноэкранным слайдером скриншотов и описанием.
- **Мобильная адаптация**: полная поддержка экранов любых размеров с сохранением всех анимаций и жестов.
- **Векторная иконографика**: 100% чистый SVG (без эмодзи).

---

## Стек технологий

- **Фреймворк**: React 19 + TypeScript
- **Сборщик**: Vite 6
- **Стилизация**: Tailwind CSS
- **Анимации**: Framer Motion
- **Иконки**: Lucide React + Inline SVG
- **Хостинг**: GitHub Pages (автоматический CI/CD деплой через GitHub Actions)
